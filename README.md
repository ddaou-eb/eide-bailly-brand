# eide-bailly-brand

A Microsoft Copilot Cowork skill that applies Eide Bailly's brand standards (approved colors, fonts,
logo files, and voice) to any Word, PowerPoint, or PDF deliverable. This repo is private: access is
by invite, coworkers can't find or clone it without being added as a collaborator.

## Install

1. Ask Daniel Daou to add you as a collaborator on this repo (GitHub Settings → Collaborators), or
   have him send you the zip directly.
2. Download this repo as a zip (Code → Download ZIP on GitHub), or clone it.
3. In Copilot Cowork, upload the folder as a new skill named `eide-bailly-brand`.

## What's in this repo

- `SKILL.md` — the skill's instructions (colors, fonts, logo rules, voice, legal entity name)
- `references/brand-guidelines-full.md` — the detailed reference (full palette, layout, voice, boilerplate)
- `assets/` — the four approved logo PNGs (primary/secondary, Black Blue/Stone White colorways)
