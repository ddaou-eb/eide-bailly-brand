# eide-bailly-brand

A Microsoft Copilot Cowork skill that applies Eide Bailly's brand standards (approved colors, fonts,
logo files, and voice) to any Word, PowerPoint, or PDF deliverable. It takes about two minutes to
install and needs no admin rights or special software.

## Install

1. Download this repo as a zip (Code → Download ZIP on GitHub), or clone it, and save the
   `eide-bailly-brand` folder somewhere easy to find, like your Downloads.
2. In OneDrive, open Documents, then Cowork. This is where Copilot keeps your skills. Open the
   skills folder, or if there isn't one yet, create a folder named exactly `skills` (all lower case).
3. Copy the entire `eide-bailly-brand` folder into `skills`. Keep everything inside it together:
   the `SKILL.md` file, the `references/` folder, and the logo PNGs all need to stay together.
4. Give OneDrive about a minute to finish syncing.
5. Open Copilot and ask it to list your skills. You should see `eide-bailly-brand` in the results.
   To see it in action, ask Copilot to create an on-brand Eide Bailly one-pager and check that it
   uses our navy-and-blue colors and drops in the logo.

**If it doesn't show up:** give OneDrive another minute and refresh, and make sure the folder sits
directly inside Documents → Cowork → skills. If Copilot shows a file-type error, check that the
folder holds only the SKILL file and PNG logo images (not EPS or WEBP).

## What's in this repo

- `SKILL.md` — the skill's instructions (colors, fonts, logo rules, voice, legal entity name)
- `references/brand-guidelines-full.md` — the detailed reference (full palette, layout, voice, boilerplate)
- `assets/` — the four approved logo PNGs (primary/secondary, Black Blue/Stone White colorways)
